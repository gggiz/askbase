AskBase 使用说明 — 永雏塔菲 RAG 智能问答系统
====================================================

【一、运行环境】
  - Windows 10/11 64 位
  - 联网（首次运行需下载模型，约 400MB）
  - 无需安装 Python 或其他依赖

【二、获取 API Key】
  注册 DeepSeek 账号：https://platform.deepseek.com
  在后台创建 API Key 并复制（形如 sk-xxxxxxxx）

【三、启动】
  双击 AskBase.exe，等待约 15~30 秒
  首次运行会下载嵌入模型（约 400MB），之后启动只需几秒
  控制台显示以下信息表示启动成功：
    ============================================
      AskBase 启动中...
      打开浏览器访问: http://127.0.0.1:7860
      按 Ctrl+C 退出
    ============================================
  手动打开浏览器访问 http://127.0.0.1:7860

【四、使用步骤】
  1. 在页面顶部输入 DeepSeek API Key，点击"设置 Key"
     （状态提示"API Key 设置成功"即可）
  2. 左侧"新建知识库"输入名称，点"创建"
  3. 上传文档（支持 PDF / TXT / MD）
  4. 右侧输入问题，点"提问"
  5. 如需计算器功能，勾选"启用 Agent"

【五、常见问题】
  Q: 首次启动很慢？
  A: 首次需下载 BGE 嵌入模型（约 400MB），之后启动只需几秒

  Q: 提问没反应？
  A: 检查 API Key 是否有效、DeepSeek 账户是否有余额

  Q: API Key 安全吗？
  A: Key 仅在当前会话内存中保存，关闭程序即消失，不会写入文件

  Q: 端口 7860 被占用？
  A: 关掉占用端口的程序，重新启动即可

  Q: 知识库数据保存在哪？
  A: EXE 同目录下的 chroma_data 文件夹

【六、分享给他人】
  把整个 AskBase 文件夹打包为 zip 发给对方
  对方解压后双击运行即可
  （API Key 需对方自备，不会内置到 EXE 中）

【七、技术栈】
  Python + Gradio + ChromaDB + DeepSeek + BGE 嵌入模型
  基于 RAG + Agent 架构
